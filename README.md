# GORTOS

an embedded operating system

## platforms:
TI MSP430FR2153 microcontroller unit


#### ryan dup

no one could ever fathom that gort would ever have an os

and then she did

behold, GORTOS!

MSP430FR2153 needs an operating system, and gort is up to the task!

fully functional with driver support for the following peripherals:

* ON-CHIP
    - universal asynchronous receiver-transmitter (UART)
    - inter-integrated circuit (I2C)
    - serial peripheral protocol (SPI)
    - analog-to-digital converter (ADC) (coming soon)
    - enhanced comparator (ECOMP) (coming soon?)
    - gpio ports ()
    
* OFF-CHIP
    - real-time clock module (RTC)
